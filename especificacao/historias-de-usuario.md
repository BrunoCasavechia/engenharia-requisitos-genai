# Histórias de Usuário — Sistema de Gestão de Eventos (Eventus)

## Participante

**HU01** — Como participante, quero visualizar todos os eventos disponíveis em um único lugar, para escolher em quais desejo me inscrever sem precisar consultar múltiplas fontes.

**HU02** — Como participante, quero me inscrever em um evento, para garantir minha participação.

**HU03** — Como participante, quero receber um comprovante logo após minha inscrição, para ter certeza de que ela foi registrada com sucesso.

**HU04** — Como participante, quero cancelar minha inscrição sem precisar contatar a organização, para resolver minha situação de forma rápida quando não puder mais comparecer.

**HU05** — Como participante, quero emitir meu certificado após o evento, para comprovar minha participação.

## Organizador

**HU06** — Como organizador, quero que o sistema controle automaticamente o número de vagas, para não precisar acompanhar isso manualmente.

**HU07** — Como organizador, quero que participantes entrem em uma lista de espera quando o evento lotar, para não perder pessoas interessadas caso surjam vagas.

**HU08** — Como organizador, quero acompanhar a quantidade de inscritos em tempo real, para ter visibilidade sobre a procura pelo evento.

## Equipe Financeira

**HU09** — Como membro da equipe financeira, quero confirmar pagamentos antes de liberar inscrições em eventos pagos, para evitar inscrições sem pagamento válido.

## Palestrante

**HU10** — Como palestrante, quero consultar a lista de participantes inscritos em minhas atividades, para me preparar adequadamente para a apresentação.
