# Requisitos Funcionais — Sistema de Gestão de Eventos (Eventus)

Requisitos identificados a partir da análise do documento de elicitação, organizados por perfil de stakeholder de origem.

## Participantes

- RF01 — O sistema deve permitir que o participante visualize todos os eventos disponíveis em um único lugar.
- RF02 — O sistema deve permitir que o participante se inscreva em um evento.
- RF03 — O sistema deve enviar um comprovante ao participante logo após a inscrição.
- RF04 — O sistema deve permitir que o participante cancele sua inscrição sem precisar entrar em contato com a organização (quando o evento permitir cancelamento).
- RF05 — O sistema deve permitir que o participante emita seu certificado após o evento.
- RF06 — O sistema deve permitir que o participante se inscreva em múltiplos workshops que ocorram no mesmo dia.

## Organizadores

- RF07 — O sistema deve permitir que o organizador crie eventos.
- RF08 — O sistema deve controlar automaticamente o número de vagas disponíveis por evento.
- RF09 — O sistema deve criar uma lista de espera quando um evento atingir a capacidade máxima.
- RF10 — O sistema deve permitir que o organizador configure se um evento aceita cancelamento de inscrição ou não.
- RF11 — O sistema deve permitir que o organizador acompanhe a quantidade de inscritos em tempo real.

## Equipe Financeira

- RF12 — O sistema deve permitir a confirmação de pagamentos antes de liberar inscrições em eventos pagos.
- RF13 — O sistema deve permitir o controle de reembolsos.

## Palestrantes

- RF14 — O sistema deve permitir que o palestrante consulte a lista de participantes inscritos em suas atividades.

---
*Nota: esta lista foi construída com apoio de IA generativa a partir do documento de elicitação e revisada manualmente. Alguns requisitos (ex.: RF04, RF09, RF05) dependem de regras de negócio ainda não definidas — ver `duvidas-e-lacunas.md`.*
